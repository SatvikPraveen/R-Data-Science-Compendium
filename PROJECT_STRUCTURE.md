# Project structure

The repository follows the *research compendium* convention (Marwick,
Boettiger and Mullen 2018, <https://doi.org/10.1080/00031305.2017.1375986>):
an installable R package holds the reusable, tested methods, and a separate
`analysis/` directory uses that package to produce the research outputs.

```
.
├── DESCRIPTION, NAMESPACE      Package metadata and exports
├── R/                          Package source: one file per method family
│   ├── bootstrap.R             boot_ci(), jackknife_influence()
│   ├── permutation.R           perm_test()
│   ├── effect-sizes.R          cohens_d(), hedges_g(), hedges_correction()
│   ├── simulation.R            run_simulation(), sim_performance(), sim_n_required()
│   ├── rng.R                   with_seed() (internal), rng_streams()
│   ├── folds.R                 make_folds()
│   ├── cross-validation.R      cross_validate(), nested_cv()
│   ├── metrics.R               auc(), auc_ci(), brier_score(), log_loss(), calibration(), ...
│   ├── data-generators.R       simulate_linear(), simulate_logistic(), ar1_cor()
│   └── utils-checks.R          Internal input validation (rdsc_error_input)
├── man/                        Reference documentation (generated by roxygen2)
├── tests/testthat/             Unit, reference-agreement and simulation-property tests
├── vignettes/                  Long-form articles (built by R CMD check and pkgdown)
├── inst/CITATION               citation("RDataScienceCompendium")
│
├── analysis/                   The research compendium
│   ├── scripts/                00-setup, 01-coverage-study, 02-cv-selection-study, 03-figures
│   ├── results/                Summarised results and provenance (tracked)
│   ├── figures/                Figures used by the paper (tracked)
│   └── paper/                  paper.Rmd and references.bib
│
├── modules/                    Stand-alone tutorial scripts and case studies (not part of the package)
├── shiny-apps/                 Stand-alone Shiny demonstrations (not part of the package)
│
├── Makefile                    Build, check and analysis pipeline (`make help`)
├── setup.R, setup.sh           Dependency installation
├── renv.lock                   Package versions used for the committed results
├── docker/, docker-compose.yml Reproducible container
├── _pkgdown.yml                Documentation website configuration
├── .github/                    CI workflows, issue and PR templates
└── CITATION.cff, NEWS.md, CONTRIBUTING.md, CODE_OF_CONDUCT.md, LICENSE(.md)
```
